# OCR language data

`eng.traineddata` is the English LSTM model from [tesseract-ocr/tessdata_fast](https://github.com/tesseract-ocr/tessdata_fast), revision `87416418657359cb625c412a48b6e1d6d41c29bd`, under the accompanying Apache 2.0 license. It is embedded in the Linux adapter so local OCR requires no language download or system tessdata directory.
