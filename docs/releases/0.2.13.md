Breadcrumb 0.2.13 fixes token count uploads and tidies the settings page.

Uploading coding-agent token counts works again. A server fix makes the permission stick, so click Allow under Settings → Coding agents once more to start uploading. If allowing fails, the row now says why.

Coding agents are now icons you click to turn reading on or off, in place of checkboxes. The last scan and last upload show relative times, such as "5 min ago". Dropdowns in Settings have a cleaner look.

Mac previews are Developer ID signed; notarization is pending. If macOS blocks the first launch, allow the app in System Settings → Privacy & Security.

Source: https://github.com/hackclub/breadcrumb/tree/v0.2.13
