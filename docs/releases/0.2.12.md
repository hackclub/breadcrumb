Breadcrumb 0.2.12 brings a new look to the app and the web portal.

The tray popup shows today as a row of crumbs, one per hour, that grow with the time you recorded. The current hour is circled. The History and Dashboard links sit on one line again.

The local dashboard and portal draw each hour in Day by hour as a crumb that grows with recorded time. Gold now marks recorded time only; buttons and controls use plain ink. Text uses Familjen Grotesk, bundled with the app, with evenly spaced numbers so times line up. The dark and light themes have new palettes; Catppuccin is unchanged.

Mac previews are Developer ID signed; notarization is pending. If macOS blocks the first launch, allow the app in System Settings → Privacy & Security.
