Breadcrumb 0.2.10 reads token usage from more coding agents and prices current models.

Settings → Coding agents now lists Grok Build, OpenCode and Antigravity beside Claude Code and Codex. Each starts off; turn on the ones you use. OpenCode and Antigravity are read from their local databases without changing them, and only model names, times and token counts are read. Grok Build counts each completed turn, including turns that route to other model providers.

API estimates now cover GPT-6 and GPT-5.6 models, Claude 5 models, Gemini 4 and Grok 4.7, so Codex usage no longer shows as Unpriced. Grok Build uses the rates Grok Build reports for each turn. OpenCode's free models cost nothing. The usage chart names each agent in its legend.

Mac previews are Developer ID signed; notarization is pending. If macOS blocks the first launch, allow the app in System Settings → Privacy & Security.
