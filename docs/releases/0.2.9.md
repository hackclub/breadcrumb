Breadcrumb 0.2.9 keeps one portal connection per computer. Capture sync and token usage uploads now share a single sign-in, and the Connections page on https://breadcrumb.hackclub.com/connections lists each computer by name. Each one shows its platform and app version, and whether it is online or when it was last used. Signing in again on the same computer replaces its older connection instead of adding another.

Token usage uploads are now a switch in Settings → Coding agents. There is no separate connection or server to set up. Connections made with earlier versions need one more permission: choose Allow, approve in your browser, and uploads start. A separate token usage connection from an earlier version is retired automatically, and its on/off choice carries over.

Settings are reorganized into Account, Recording, Privacy, Storage, Coding agents, App and Diagnostics sections. A single bar saves or discards changes.

Mac previews are Developer ID signed; notarization is pending. If macOS blocks the first launch, allow the app in System Settings → Privacy & Security.
