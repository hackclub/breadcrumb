Breadcrumb 0.2.11 makes downloads and updates much smaller.

Windows setup is now about 16 MB instead of over 300 MB. Windows 10 and 11 already include the Microsoft Edge WebView2 runtime; if it is missing, setup installs it silently, which needs an internet connection. The app and its local engine are built smaller on every platform, so updates download faster.

The tray popup no longer loads the local dashboard's charts and pricing table; the dashboard window loads them when it opens.

Mac previews are Developer ID signed; notarization is pending. If macOS blocks the first launch, allow the app in System Settings → Privacy & Security.

Source: https://github.com/hackclub/breadcrumb/tree/v0.2.11
